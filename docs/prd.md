# 产品需求

本文件按用户任务说明现有能力、默认与可选行为，以及结果应满足的条件。[Formulation](formulation.md)解释问题与观测边界，[RFC](rfc.md)解释当前实现，[测试说明](test.md)规定验证方法。已实现表示代码存在可达入口，不表示每个房间默认启用、每种部署均已验收或主播已经实际使用。

## 1. 开始盯房间，保留本场记录

用户输入房间号或链接即可添加监控，也可停止单个房间。默认记录音频和网页接收到的事件；录制、语音识别和缩略图是三个独立选项。录制可选none/audio/video，默认audio；实时ASR和缩略图默认关闭。原始录制独立保留，不能与处理后删除的ASR临时素材混为一谈。

audio模式使用网页PCM，关闭ASR也仍需播放。video模式可在不开ASR和预览时暂停网页视频，由FFmpeg录制媒体流；none不生成录音录像。开启实时ASR后，按每房间独立上下文持续修订当前转写，不将其当作已人工核验的定稿。

弹幕、礼物/付费互动、个人点赞通知与转写按事件时间展示，来源和状态可区分。前端保留每房间最近80条时间线和20段识别指标；完整历史保存在SQLite，可全库或按房间导出JSONL。支持全宽、全屏、跟随最新和上翻暂停。显示条数不是存储上限。

验收关注：停止后不再发布迟到识别结果；一个房间的数据不混入另一个；未知或失败不伪装成零、正常静音或已完成。

## 2. 长期守候，查看多个实例

平台支持候选轮转和固定名单守候。固定模式按开播状态启停，未开播不占直播标签页；平台目标可持久恢复，临时添加的房间在服务重启后不自动重开。手动rotate-live与平台自动策略是不同入口，具体执行条件见[平台运维](../skills/bilibili-live-monitor/platform-operations.md)。

账号和匿名profile隔离Chrome目录。匿名模式不登录、不欢迎、不点赞；昵称分析身份不得冒充UID或自动合并历史UID档案。统一网关汇总配置的本机实例并提供归档入口，不接管采集进程。

验收关注：守候、采集中、需人工处理等状态准确；账号之间不共享会话或操作目标；网关不把私有路径和控制元数据暴露给浏览器。

## 3. 在播跟进，下播继续看同一结果

可选单场看板展示趋势四图、活动分类、歌名登记与灯牌/盲盒点歌跟进。采集器不自行认证歌名或现场演唱；分析和登记保留各自证据要求。

自动逐场工作流默认关闭。启用后可自动建场、巡检、离线转写与终审，并更新同一路径。local_only保留本地处理而不发布远端。AI、通知与远端发布各按配置和授权执行；不能从接口存在推断已经开启。

验收关注：直播、收尾和完成阶段与实际处理状态对应；录制优先，分析失败不丢原始记录；恢复不换到另一场、不重复通知。完成态不自动证明每项分类或金额都正确。

## 4. 跨场回看场次、歌曲和观众

房间归档同时提供完整场次汇总与北京时间自然日入口。整场按开播日期归属，跨午夜不拆整场；自然日统计按自己的窗口计算。双轴图展示平均在线和每场礼物总金额，表格保留详细指标。历史缺少本地详情时，仅使用显式配置的安全来源回退链接。

歌曲目录、歌曲期间礼物/关注分析、观众关系备忘是独立可选产物，不是每个房间主页默认包含的字段。观众备忘涉及昵称、互动、承诺与引用，即使去UID仍可能识别人，不得默认随普通统计页发布。

验收关注：历史链接与人工审核结果保持；数字的单位、缺测、时间范围和来源可解释；同一汇总JSON在两个页面显示一致，只证明传递一致，不证明上游计算正确。

## 5. 授权互动与助手操作

一次性/单场欢迎脚本默认dry-run，经明确授权才执行。持久自动欢迎按已配置房间规则及开关运行，不等于所有欢迎入口默认关闭。点赞须指定目标、次数和请求身份；账号切换保留实例隔离。已有assistant支持卡片修改、撤销、注音与AI控制，不能把存在这些入口写成主播实际采用的证明。

验收关注：操作落在正确房间，发送与完成回执如实表达；失败和未知结果不盲目重发；原有启用状态不会因普通浏览或构建而改变。

## 6. 处理已有素材

已有录音录像可独立离线转写、生成趋势/活动分析、制作预告片、压缩归档。永久清理需独立显式开启，不属于直播收尾默认路径。各入口的依赖与操作流程见[根skill](../skills/bilibili-live-monitor/SKILL.md)。

## 结果契约与验收边界

礼物总金额不是件数乘已给出的总价，也不是主播实收。未知与零不同；累计看过不是跨场去重观众；粉丝净变化不是新增关注事件数；匿名昵称不是可靠的跨场个人ID。活动尾窗可能重叠，不能直接相加当作整场。具体统计规则和消费者差异见RFC。

验收采用自动测试、少量典型历史场次抽查和页面操作，具体见[test.md](test.md)。线上数字是对照而非天然正确答案；轻微刷新或舍入差异无需逐项追查，明显异常才回看原始记录、按需独立验算，修正有错的实现后复看。报告如实说明发现的问题和限制，不把抽查结论写成全量保证。

默认容量配置不代表实测承诺。旧独立切片的多路短测不代表当前流式容量或长期稳定性。本地ASR无需付费识别API；可选外部模型仍可能产生费用。真实录音、转写、身份、配置及验证证据不进入公开仓库。
